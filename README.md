# GEO 이미지 분해기

**v1.0** · 화면 우측 상단 헤더에도 현재 버전이 표시됩니다 (`v1.0` 배지). 업데이트된 파일을 받으셨는데 화면의 버전이 그대로라면, 파일이 제대로 덮어써지지 않은 것이니 다시 받아주세요.

통이미지(긴 인포그래픽형 상품 상세페이지 이미지)를 AI 검색(GEO)에 최적화된
텍스트 + 이미지 구조로 재구성해주는 도구입니다. 서버·설치 없이 **HTML 파일 하나**로 동작합니다.

## 버전 기록
- **v1.0** — 블록 순서 변경(▲▼), 삭제/이동 시 다른 블록 수정 내용이 사라지던 버그 수정, 원본↔결과 연결 보기, 검수 상태 요약, 하단 고정 액션 바, 설정 팝업 등 현재까지의 기능을 묶은 기준 버전

## 설치형(PWA)으로 쓰기

레포에는 `index.html` / `manifest.json` / `sw.js` / 아이콘이 이미 들어있어서, **GitHub Pages로 호스팅하면 브라우저의 "앱 설치" 기능으로 바로 설치할 수 있습니다.**

1. 이 레포를 GitHub에 올리기
2. 레포 Settings → Pages → Source를 "main 브랜치, / (root)"로 설정 → 저장
3. 몇 분 뒤 `https://<계정명>.github.io/<레포명>/` 주소가 생성됨
4. 그 주소를 Chrome/Edge로 열면 주소창에 설치 아이콘이 뜨고, 눌러서 설치하면 독립된 창으로 열리는 앱처럼 씁니다

⚠️ **로컬에서 그냥 파일을 더블클릭해서 여는 경우(`file://`)에는 설치 버튼이 뜨지 않습니다.** PWA 설치는 `https://` 또는 `localhost`로 서빙될 때만 동작하는 브라우저 표준 제약입니다. 설치형 없이 그냥 열어서 쓰는 것도 당연히 계속 가능합니다 (`geo-image-splitter.html`을 다운받아 더블클릭).

아이콘(`icon-192.png`, `icon-512.png`)은 지금 임시로 만든 단색 플레이스홀더입니다. 브랜드 로고로 같은 파일명으로 교체하면 바로 반영됩니다.

## 사용 방법

1. `geo-image-splitter.html` 파일을 다운로드해 더블클릭(또는 브라우저로 열기)
2. 최초 1회만: 우측 상단 **⚙ API 설정**에서 본인의 Anthropic API 키 입력 (https://platform.claude.com 에서 발급). 저장되면 버튼이 "API 설정 완료 ✓"로 바뀌고, 이후엔 다시 입력할 필요 없음
3. 상품번호 입력 + 통이미지 업로드 (순서대로, 여러 장 가능)
4. "통이미지 분석하기" 클릭 → Claude가 텍스트/이미지로 자동 분류
5. 추출 결과를 확인하고 필요하면 직접 수정 (텍스트 수정, 이미지 자르는 범위 슬라이더 조정)
6. 화면 아래에 고정된 **"HTML 생성하기 →"** → 카페24 상세설명에 붙여넣을 HTML과, 잘라낸 이미지 파일들이 생성됨
7. 이미지는 먼저 카페24 에디터에 업로드해 URL을 받고, HTML 안의 `__IMG_01_URL__` 같은 자리를
   실제 URL로 교체한 뒤 저장
8. 여러 상품을 처리한 뒤 "CSV로 내보내기"를 누르면, 상품번호+상세설명 열을 가진 CSV가
   다운로드됩니다. 이 CSV의 두 열을 카페24 "상품관리 > 상품 정보 일괄 변경" 엑셀 양식에
   옮겨 붙이면 한 번에 여러 상품을 갱신할 수 있습니다.

## 알아둘 점

- **API 키는 브라우저에만 저장**됩니다 (localStorage). 외부 서버로 전송되지 않고,
  분석 요청 시 Anthropic API로 직접 전송됩니다. 다만 브라우저에서 직접 호출하는 방식이라
  네트워크 탭 등에서 키가 노출될 수 있습니다. 팀 공용 키보다는 사용량 제한을 건
  개인 키 사용을 권장합니다.
- **카페24 자동 업로드는 지원하지 않습니다.** 카페24 Open API 연동이 없는 환경에서
  동작하도록 만들어졌기 때문에, 이미지 업로드와 최종 반영은 수작업입니다. 이 도구는
  "어느 게 텍스트고 어느 게 이미지인지 판단 + 글 재구성"이라는 가장 품이 많이 드는
  단계만 자동화합니다.
- **다른 LLM 프로바이더로 교체하기**: `analyzeImages()` 함수 안의 `fetch` 호출
  (`callClaudeVision`에 해당하는 부분)만 바꾸면 됩니다. 단, Anthropic API는
  `anthropic-dangerous-direct-browser-access` 헤더로 브라우저에서 직접 호출하는 것을
  공식 지원하지만, 다른 프로바이더(OpenAI, Gemini 등)가 동일한 방식의 브라우저발
  CORS 호출을 허용하는지는 프로바이더별로 별도 확인이 필요합니다. 확인 없이 호출부만
  바꾸면 CORS 오류로 동작하지 않을 수 있습니다.
- 생성된 HTML은 `<script>` 태그나 `<table>` 안의 이상한 중첩을 피하기 위해 의도적으로
  단순한 구조(시맨틱 태그 + 하나의 `<style>` 블록)로만 작성됩니다. 카페24 상세설명
  에디터가 `<script>` 태그를 저장 시 필터링하는 경우가 있어, JSON-LD 구조화 데이터는
  이 도구의 출력에 포함하지 않습니다.
